About BLOCKNATOR

BLOCKNATOR is a modular Web3 infrastructure that stores, organizes and presents token projects across multiple blockchains. All projects belong to the BLOCKNATOR ecosystem but operate independently on their respective networks.

What BLOCKNATOR does

  • Stores information and files for the projects.
  • Maintains a central token directory.
  • Presents the projects through a gallery.
  • Provides access to the official Web3 pages.
  • Organizes information and official links.

Architecture

Ultralight 100% client-side architecture: zero backend, zero databases, zero heavy frameworks. The static server only delivers files; your browser interprets and runs them using HTML5, CSS3, native JavaScript and JSON.
